طريق المجال — صور تواقيع البريد الإلكتروني
=========================================

هذه الصور مستخدمة داخل أكواد التواقيع العشرين.

طريقة الاستخدام:
1) ارفع كل ملفات هذا المجلد إلى استضافة على الإنترنت
   (موقع الشركة، أو أي خدمة استضافة صور تدعم روابط مباشرة).
2) في كود التوقيع، استبدل المسار:
       https://www.tareeqalmajal.com/email
   بالرابط الفعلي للمجلد الذي رفعت إليه الصور.
   مثال: إذا رفعتها إلى  https://yoursite.com/sig
   فاستبدل كل ظهور للمسار القديم بهذا الرابط.
3) انسخ كود التوقيع المطلوب والصقه في:
   Outlook ▸ File ▸ Options ▸ Mail ▸ Signatures

ملاحظات:
- الشعارات بصيغة PNG بخلفية شفافة (logo-color للخلفيات الفاتحة،
  logo-white للخلفيات الداكنة بلون العلامة).
- الأيقونات: badge = دائرة باللون مع رمز أبيض، teal = رمز خطي،
  white = للخلفيات الداكنة.
